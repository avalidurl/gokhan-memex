Preview · MVP under construction · Public roadmap and docs.

Roadmap

The product is in v0.0: documentation and intake. The first private alpha loop is the next gate.

Current status

  • Network: Base.
  • Token: BOUNTY (reviewer bonding only, not a payment unit).
  • Public surface: roadmap, docs, beta waitlist.
  • Bounty loop: not live yet. Curated sponsors and reviewers will run the first loop.

Timeline

30-day plan

  1. Ship public roadmap and docs site.
  2. Open beta waitlist via Tally.
  3. Stand up a private alpha loop with curated sponsors and reviewers.
  4. Run a small number of real bounties end to end on Base testnet first.
  5. Publish public proof of the first paid loops.
