Onchain Agent Bot Services

$ ticker $ONBOTS # coming soon

Onchain agent bots as services — spin up agents that deploy, watch, and act onchain without babysitting a laptop process.

## services

onbots@chain:~ 
# agent bot CLI — sample surface
$ onbots deploy  --agent trader --chain base
  ok  bot_id=0xagent… deployed

$ onbots monitor --bot 0xagent… --alerts webhook
  ok  watching slots · heartbeat 12s

$ onbots execute --bot 0xagent… --job swap
  ok  queued · waiting confirmation

$ onbots fees    --bot 0xagent… --report
  ok  gas · tips · service fee summary

$ onbots █
  • deploy — stand up an agent bot onchain
  • monitor — heartbeats, alerts, run health
  • execute — trade / job execution hooks
  • fees — fee + tx tooling and reports
