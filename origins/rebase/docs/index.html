REBASE

REBASE is an elastic-supply ERC-20 on Robinhood Chain (4663). It targets $1.00. It is not a Robinhood Stock Token and is not listed in the Robinhood Crypto app.

Displayed balances move when a daily policy updates a single scalar. There is no loop over holders. A rebase is one transaction.

balanceOf(user) = gons[user] / gonsPerFragment

Uniswap never holds raw REBASE. It holds wREBASE, a static wrapper.
