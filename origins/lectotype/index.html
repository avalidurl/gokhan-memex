01 · Doctrine

  • If it is not in L1 state or events, it is not canon.
  • No strings in storage — only bytes32 contenthashes.
  • No AMM. No launcher. Pairs are pointers, not products.
  • One specimen per token address. Parent edge optional.

05 · Anti-spam

Permissionless mint without friction fills the shelf with noise. Draft gate:

  1. Bond — posted at register; returned if unchallenged after N days.
  2. Liquidity floor — primary pair must clear a minimum at register time.
  3. Challenge window — contested contenthash / parent / template can be disputed; winner written back on L1.

06 · Cost posture

Expect roughly 200–400k gas per register. Pack structs. Fat events for indexers; skinny SSTORE. Multicall for curator backfill of historical specimens. Immutable v1 preferred; if upgradeable, UUPS + timelock.

  ┌─────────────────────────────────────┐
  │  fat EVENT logs     cheap to emit   │
  │  skinny SSTORE      expensive, rare │
  │  bytes32 only       no strings fren │
  │  multicall backfill curator pays    │
  └─────────────────────────────────────┘

         v
   pepe pays gas once → canon forever

07 · Ship ladder

  1. Specimen NFT + one-per-token + contenthash + parentId
  2. Curator-funded backfill of the historical set (so the shelf isn’t empty)
  3. Permissionless register with bond + liquidity floor
  4. Read-only explorer (state + logs only)
  5. Caught proofs, if collection gameplay is wanted
