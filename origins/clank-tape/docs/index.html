Clanker API notes

quirks we encode 
• User-Agent required (ClankTape/0.1)
• Do not pass limit= — use default page size (~10) + cursor=
• sortBy that work: deployed-at · market-cap
• Fee encodings differ by regime:
    tax_v0  buyTaxRate/sellTaxRate in 1e-4 bps (1_000_000 = 100 bps = 1%)
            split shares in 1e8 (100_000_000 = 100%)
    v4_*    clankerFee/pairedFee (and baseFee/maxFee) in 1e-2 bps
            (10_000 = 100 bps); recipients[].bps sum to 10_000
• Trending token map keys may differ in checksum case → lowercase lookup
• Source of truth for fields: live payloads, not assumed SDK shapes

Aeon?

agent runtime vs this board 
Do we use Aeon here?
  NO — not for the Daily Tape refresh.

Clank Tape refresh = deterministic Python snapshot on GitHub Actions.
Aeon (aeon.fun) = LLM agent runtime that also uses GitHub Actions, with
skills/, model secrets, and cron that *thinks*.

Use Aeon later only if you want agentic briefs/alerts on top of the tape.
Do not wrap snapshot.py in Aeon just to republish static HTML.
